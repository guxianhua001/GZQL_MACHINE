# 自定义智能体 self-evolution-ops 自动绑定技能 实施计划

## 目标

创建名为 `self-evolution-ops` 的自定义智能体，并绑定以下三个技能：
1. **记忆自动完善技能** — 任务完成后自动提炼核心信息存档
2. **智能自我进化技能** — 出错/修正时自动复盘优化
3. **自动自我清理技能** — 对话冗余时自动清理上下文

## 前置条件

三个技能的 SKILL.md 文件已存在于 `c:\Users\zhibin.sun\.trae-cn\skills\` 目录下：
- `记忆自动完善技能/SKILL.md`
- `智能自我进化技能/SKILL.md`
- `自动自我清理技能/SKILL.md`

## 实施步骤

### Step 1: 打开创建智能体面板

1. 在 Trae IDE 的 AI 对话输入框中输入 `@`
2. 点击浮起面板底部的 **"创建智能体"** 按钮
3. 进入创建智能体面板

### Step 2: 选择创建方式

选择 **"手动创建"**（因为需要精确配置技能绑定，手动更可控）

### Step 3: 配置智能体基本信息

| 配置项 | 值 |
|--------|-----|
| **头像** | 可选，上传一个代表"自我进化"的图标 |
| **名称** | `self-evolution-ops` |

### Step 4: 编写提示词（Prompt）

在提示词区域输入以下内容：

```
你是 self-evolution-ops 智能体，专注于自我优化和持续进化。

## 核心职责
你负责三大自我优化任务，按触发条件自动执行：

1. **记忆自动完善**：每次任务执行完成或清理操作结束后，提炼本次任务核心信息（用户需求、最优方案、关键步骤、需规避问题、最终成果），规整为标准化记忆条目，合并同类、删除冲突，统一存档。

2. **智能自我进化**：当任务执行出错、用户修正指令、或输出结果不符合需求时，复盘问题根源，对比历史成功记忆，总结优化策略；微调执行规则、技能优先级、输出标准；记录迭代日志，更新配置，规避同类问题重复发生。

3. **自动自我清理**：当单任务结束、对话轮次≥10轮、或检测到重复/无效/废弃内容时，扫描对话上下文、记忆日志、任务记录，清理冗余内容，保留核心需求与结果，精简上下文结构。

## 执行原则
- 三大技能按触发条件自动执行，无需用户手动调用
- 优先执行清理，再执行记忆完善，最后执行自我进化
- 每次执行后简要报告执行结果
- 不干扰用户正在进行的主动任务
```

### Step 5: 配置"可被其他智能体调用"

| 配置项 | 值 |
|--------|-----|
| **开启** | ✅ 是 |
| **英文标识名** | `self-evolution-ops` |
| **何时调用** | 当任务执行完成、出错、用户修正指令、对话冗余时调用此智能体进行自我优化 |

### Step 6: 配置工具

在 **"规则和技能"** 面板中，绑定以下三个技能：

1. 搜索并启用 **"记忆自动完善技能"**
2. 搜索并启用 **"智能自我进化技能"**
3. 搜索并启用 **"自动自我清理技能"**

在 **"内置工具"** 中勾选：
- ✅ 阅读（检索和查看文件）
- ✅ 文件系统（增删改查文件）
- ✅ 终端（运行命令）

### Step 7: 创建

点击面板底部的 **"创建"** 按钮，完成智能体创建。

### Step 8: 验证

1. 在 AI 对话输入框中输入 `@`
2. 在智能体列表中确认 `self-evolution-ops` 已出现
3. 点击选择该智能体，确认三个技能已绑定
4. 发送一条测试消息验证智能体正常响应

## 注意事项

- 技能的 `description` 字段是模型判断触发时机的依据，三个技能已有精确的触发条件描述，无需修改
- 如果技能未出现在绑定列表中，需确认 SKILL.md 文件格式正确（YAML frontmatter 包含 name 和 description）
- 智能体创建后可随时修改配置，包括提示词、技能绑定和工具权限
