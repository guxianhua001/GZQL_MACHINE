# DLS椭圆拟合功能禁用设计文档

**日期：** 2026-05-20
**状态：** ✅ 已批准
**范围：** CadAlignmentViewModel.cs - 禁用DLS椭圆拟合调用

---

## 1. 背景

### 1.1 问题
- CAD对位视图（CadAlignmentView）在导入DXF文件后，会使用Direct Least Squares (DLS)算法拟合椭圆
- 拟合生成的蓝色圆弧与原始CAD轨迹存在偏移
- 偏移原因：原始CAD中的弧形轨迹不是标准圆弧，而是由多条小线段连接组成

### 1.2 用户需求
- 取消DLS拟合圆弧显示
- 只保留真实CAD数据（POLYLINE折线段 + CIRCLE标记点）

---

## 2. 解决方案

### 2.1 方案选择
**✅ 选择方案：仅禁用调用（推荐）**

理由：
- 保留DLS算法代码以备将来可能需要
- 可随时重新启用
- 零风险，完全可逆

### 2.2 实施细节

#### 修改文件
`Module\Controls\Assembly\CadAlignmentViewModel.cs`

#### 修改位置
第836-838行

#### 修改内容
```csharp
// ❌ 已禁用DLS椭圆拟合：拟合圆弧有偏移，不如不显示
// 原始CAD中的弧形轨迹由POLYLINE折线段和CIRCLE标记点表示
// TryGenerateFittedEllipse();
```

#### 保留代码
- `TryGenerateFittedEllipse()` 方法（第869-971行）
- `FitEllipseDLS()` 算法实现（CadEntityHalconExtensions.cs）
- `FitEllipseFromPoints()` XLD生成方法
- 所有DLS相关调试日志
